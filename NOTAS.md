Escorpião OS — Linux feito do zero com o livro **Linux From Scratch 12.4 (ARM64)** e o **BLFS 12.4**.

- **No celular:** o app Jarvis baixa o `escorpiao-os-arm64.tar.gz` e instala sozinho.
- **No computador ARM64 / máquina virtual (UEFI):** use o `escorpiao-os-arm64.iso` (usuário `root`, senha `escorpiao`; para a área de trabalho: `startx`).
- Kernel Linux 6.16.1 (`escorpiao-kernel-*.efi`), GCC 15.2, glibc 2.42, XFCE 4.20, TigerVNC 1.15, Firefox 140 ESR.
- Códigos-fonte: `codigos-fonte.tar.parte*` (junte com `cat codigos-fonte.tar.parte* > fontes.tar`).
- Confira os arquivos com `SHA256SUMS`.
